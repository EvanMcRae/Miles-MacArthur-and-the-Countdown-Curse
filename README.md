# Miles MacArthur and the Countdown Curse

Made for the 2026 GMTK Game Jam (theme: "Count Down").
- Engine: Unity 6000.4.9f1
- Development time: 96 hours

Play here: https://evanmcrae.itch.io/miles-macarthur-and-the-countdown-curse

##  Description
Help free treasure hunter pro Miles MacArthur from the Countdown Curse by solving puzzles and navigating maze-like structures under a strict time limit. Use knowledge gathered in previous runs to claw closer to the finish with each new attempt.

Doomed to a cycle of near-constant death and rebirth, Miles MacArthur must navigate labyrinthian "scapes" to bring himself closer to freedom from this grim fate. As Miles, you will find special treasures and utilize their unique powers to venture deeper into these mazes towards salvation.

Can you escape the Scapes and break the curse once and for all?

## Controls
- WASD/Arrow Keys: Move
- Q/Z: Pick up
- E/X: Use
- TAB/Backspace: Pause
  - ESC instead of TAB in downloaded version
- R: Quick reset
